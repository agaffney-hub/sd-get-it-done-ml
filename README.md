# San Diego Get It Done Machine Learning Analysis

#### Project Description: 
The [City of San Diego’s Get It Done application](https://www.sandiego.gov/get-it-done) allows residents to report
non-emergency issues such as potholes, graffiti, abandoned vehicles, and other problems that
require city attention. Our project will investigate whether machine learning can predict how
long these cases will take to resolve based on factors such as incident type, location, and time of
submission. We plan to use linear regression to predict case resolution time, logistic regression to
classify cases based on whether they are resolved within a defined time period, and k-means
clustering to identify groups of cases with similar characteristics and resolution patterns. These
models could help identify factors associated with longer resolution times and demonstrate how
machine learning could potentially support San Diego’s service management for this Get It Done
program.
